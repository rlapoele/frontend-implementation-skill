## [1.0.0] - 2026-10-19

### Added

- Initial stable release of the `build-frontend-experiences` portable agent
  skill.
- Framework-independent guidance for domain-appropriate frontend implementation,
  semantic HTML, WCAG 2.2 AA accessibility, responsive behavior, interaction
  states, client-side safety, and controlled product scope.
- Focused reference guidance for interface design, expressive landing pages and
  media, animation, games, canvas and 3D experiences, plus browser verification
  and implementation handoff.
- Codex display metadata and installation instructions for Codex, Claude Code,
  Agent Skills-compatible tools, generic models, and custom agent harnesses.
- Apache License 2.0 licensing and provenance notices in both the repository and
  distributable skill directory.
- Ignore rules for common operating-system, IDE, editor, environment, dependency,
  and build artifacts.
